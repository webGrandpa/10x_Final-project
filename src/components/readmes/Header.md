კომპონენტის დასაწყისში, useState ჰუკების მეშვეობით, ჩვენ ვქმნით ცვლადებს, რომლებიც ინახავენ კომპონენტის მდგომარეობას. ეს ცვლადები აკონტროლებენ, თუ რა გამოჩნდეს ან წაიშალოს:

const [menuOpen, setMenuOpen] = useState(false);
აკონტროლებს ბურგერ მენიუს ხილვადობას მობილურ ვერსიაზე. true ნიშნავს, რომ მენიუ ღიაა, false — დახურული.
const [showLoginModal, setShowLoginModal] = useState(false);
მართავს შესვლის მოდალური ფანჯრის ხილვადობას.
const [showRegistrationModal, setShowRegistrationModal] = useState(false);
მართავს რეგისტრაციის მოდალური ფანჯრის ხილვადობას.
const [showForgotPasswordModal, setShowForgotPasswordModal] = useState(false);
მართავს პაროლის აღდგენის მოდალური ფანჯრის ხილვადობას.
const [isLoggedIn, setIsLoggedIn] = useState(false);
განსაზღვრავს, შევიდა თუ არა მომხმარებელი სისტემაში. მისი მნიშვნელობა იცვლება true-ზე, როდესაც მომხმარებელი წარმატებით შედის.
const [userEmail, setUserEmail] = useState('');
ინახავს მომხმარებლის ელ. ფოსტას, რომელიც შეყვანილი იქნა შესვლის ფორმაში.

დამხმარე ფუნქციები:

handleLoginSuccess(email): ეს ფუნქცია გადაეცემა LoginModal-ს. როდესაც მომხმარებელი შევა სისტემაში, LoginModal გამოიძახებს ამ ფუნქციას და გადასცემს მას მომხმარებლის ელ. ფოსტას. ამ ფუნქციის შიგნით, ჩვენ setIsLoggedIn(true)-ის საშუალებით ვცვლით მომხმარებლის სტატუსს და setUserEmail(email)-ით ვინახავთ მის ელ. ფოსტას.

handleLogout(): ეს ფუნქცია გამოიყენება მომხმარებლის სისტემიდან გამოსასვლელად. ის აბრუნებს isLoggedIn-ს false-ზე და აცარიელებს userEmail ცვლადს.

useEffect: ეს ჰუკი გამოიყენება გვერდითი ეფექტების სამართავად. თქვენს შემთხვევაში, ის უზრუნველყოფს, რომ მოდალური ფანჯრის ან მენიუს გახსნისას გვერდი აღარ ისქროლება (document.body.classList.add('no-scroll')). ასევე, ის ამატებს mousedown ლისენერს, რომელიც მენიუს ან მოდალური ფანჯრის გარეთ დაჭერისას მათ ხურავს.

გვაქვს პირობითი რენდერინგი რომელიც ამოწმებს ლოგინის მნიშვნელობას
თუ true: გამოჩნდება Link კომპონენტი, რომელიც შეიცავს პროფილის იკონკასა და მომხმარებლის ელ. ფოსტას. ამ ბლოკზე დაჭერით მომხმარებელი გადავა /userprofile მარშრუტზე. ასევე, გამოჩნდება ღილაკი „გამოსვლა“, რომელიც handleLogout ფუნქციას გამოიძახებს.

თუ false: გამოჩნდება ღილაკები „შესვლა“ და „რეგისტრაცია“, რომლებიც გახსნიან შესაბამის მოდალურ ფანჯრებს.
